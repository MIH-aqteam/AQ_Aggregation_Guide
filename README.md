# AURA Data Aggregation Guide

Independent Sphinx component under AURA resources.

Local build: `./local.sh`. Testing publication: `./publish.sh`.

Production publication script deliberately not supplied until EEA destination is agreed.

## PDF version (manual)

Export the approved guide to PDF from Word and name it
`AQ_Data_Aggregation_Guide.pdf`. Place it in `source/_static/`,
then run `./local.sh`. The sidebar PDF version link will open this file.
The PDF is deliberately not generated by any script.

## Sidebar subsections

The expandable chapter navigation is provided by `_static/aura-sidebar.js`.
Chapter subsections are drawn from the Markdown heading structure.
Check subsection links in the local HTML build before publishing.
